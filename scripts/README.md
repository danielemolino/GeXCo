# Helper scripts

Run from the repository root after [installation](../README.md#installation).

| Script | Usage |
|---|---|
| `smoke.py` | `python scripts/smoke.py --output-dir outputs/smoke` |
| `download_checkpoints.py` | `python scripts/download_checkpoints.py --gexco --maisi --output-dir checkpoints` |

See [test coverage](../tests/README.md) and the
[MAISI setup](../gexco/data/README.md#download-the-frozen-maisi-vae).
Pipeline stages are available through the installed `gexco` CLI.
